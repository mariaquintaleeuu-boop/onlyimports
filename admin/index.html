Panel de Only Imports

Ingresá tu clave de acceso para administrar productos, stock y diseño.

¿Cómo consigo la clave?
  1. Entrá a github.com con la cuenta de la tienda.
  2. Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token.
  3. En "Repository access" elegí solo el repositorio de la página.
  4. En "Permissions", Contents: Read and write.
  5. Generá el token, copialo y pegalo acá. Queda guardado en este dispositivo.
